# Lunoupe — Credits

Everything in Lunoupe that was made by someone else, and under which licence. Where an asset is offered under several licences, any one of them can be followed — OGA-BY 3.0 is the simplest when it is listed.

Everything else — the scenes, props (desk, cup, pillow, rug, mop), icons and app icon — was drawn by the creator of Lunoupe.

## Licences followed

Some sprites offer a choice of licences; only one needs to be followed:

- **OGA-BY 3.0** wherever it is offered (most sprites)
- **CC-BY-SA 3.0** for five hairstyles that don't offer OGA-BY: long messy, ponytail, unkempt, bedhead, messy
- **CC0** where that is the only licence (no conditions)

All of them ask for credit, which this file and the in-app Credits page give. CC-BY-SA adds one rule: if those five hairstyles are ever edited, the edited sprites must be shared under CC-BY-SA too.

## Character sprites

From the Liberated Pixel Cup (LPC) collection, assembled with the Universal LPC Spritesheet Character Generator: https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator

One entry per sprite. Colour variants use the same sprite, so they share its credit: bodies, heads and faces cover all eight skin tones (amber, bronze, brown, light, olive, peach, porcelain, taupe); hair covers both colours (dark brown, sandy).
